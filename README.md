# SereneMind Care — Mental Health Counseling & Psychological Wellness Sanctuary HTML Template

A modern, commercial-grade, ThemeForest/TemplateMonster-ready HTML5/CSS3/JavaScript template designed for **Mental Health Counseling Centers, Licensed Clinical Psychologists, Marriage & Family Therapists, Trauma Centers, and Wellness Practices**.

---

## 🌟 Key Highlights & Features

### 1. 100% Focused on Mental Health & Psychological Wellness
- **Zero Generic or Distorted Imagery:** Every hero, service card, therapist profile, blog article, and sanctuary interior uses curated, high-resolution photography with `object-fit: cover` and proper aspect ratios.
- **Calming Clinical Aesthetics:** Designed with clinical teal (`#0d9488`), serene indigo (`#6366f1`), warm sand, and slate palettes to provide a non-clinical, welcoming, and trustworthy experience.
- **Pure Frontend Architecture:** Pure semantic HTML5, CSS3, Tailwind CSS, Font Awesome 6, and clean Vanilla JavaScript (`assets/js/main.js`). No React or heavy build tool dependencies.

### 2. Dual Themes (Dark & Light Mode) + Bidirectional RTL Support
- **Persistent Theme Toggle:** Instant switching between Dark and Light mode with `localStorage` persistence.
- **Full RTL (Right-to-Left) Support:** Complete native layout support for Arabic and Hebrew languages (`dir="rtl"`), including text alignment, flex directions, icons, and navigation drawers.

### 3. Interactive Healthcare & Therapeutic Tools
- **Universal Appointment Booking Modal:** Pre-fills service and therapist selections, validates fields, and issues a realistic confirmation toast notification.
- **Interactive 4-4-4-4 Box Breathing Visualizer:** Real-time 4s Inhale, 4s Hold, 4s Exhale, 4s Hold clinical visualizer with concentric breathing pulse animations, phase prompts, and completed cycle counter.
- **Mental Wellness Screener (PHQ-9 / GAD-7 Benchmark):** 3-question scoring assessment that computes immediate clinical guidance and direct booking recommendations.
- **Transparent Pricing Switcher:** Monthly vs Annual care plan switcher with automated 20% discount recalculation.
- **Live Search & Category Filter Engines:** Real-time filtering across Services, Therapists, and Wellness Blog without page reloads.
- **Toast Alert System:** Accessible, non-intrusive floating notifications for all user actions.
